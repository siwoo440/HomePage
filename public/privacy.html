운영 전 검토용 초안

DEVFORGE 개인정보처리방침

작성 기준일: 2026년 9월 23일

1. 현재 처리 범위

현재 로컬 시연 사이트는 회원가입 정보를 서버에 저장하지 않습니다. 문의 주소와 실제 외부 계정도 아직 연결하지 않았습니다.

2. 브라우저 로컬 저장소

관심 프로젝트와 최근 본 프로젝트 식별자는 이용 중인 브라우저 로컬 저장소에만 기록됩니다. 이 정보는 서버로 전송하지 않으며 보관함의 삭제 버튼 또는 브라우저 설정에서 지울 수 있습니다.

3. 선택형 분석 저장

개인정보 설정 화면에서 분석 저장에 동의한 경우에만 사이트 이용 분석 기능이 활성화됩니다. 실제 분석 서비스가 설정되지 않은 환경에서는 외부 전송이 발생하지 않습니다.

4. 상담과 외부 서비스

유효한 상담 서비스 설정 키가 없는 경우 외부 상담 스크립트를 불러오지 않습니다. 향후 외부 서비스가 연결되면 제공 업체, 처리 항목, 보유 기간을 실제 설정에 맞춰 이 문서에 추가해야 합니다.

5. 운영 전 확인 사항

운영자 정보, 연락처, 서버 저장 항목, 위탁 업체가 확정된 뒤 실제 처리 흐름과 일치하도록 최종 검토해야 합니다. 이 문서는 법률 전문가의 최종 검토를 거치지 않은 초안입니다.
