DEVFORGE 개인정보처리방침

작성 기준일: 2026년 9월 23일

영어 화면은 참고용 자동 번역이며, 내용이 다르면 한국어 원문이 우선합니다.

1. 현재 처리 범위

현재 로컬 시연 사이트는 회원가입 정보를 서버에 저장하지 않습니다. 문의 주소와 실제 외부 계정도 아직 연결하지 않았습니다.

문의하기 페이지의 문의 양식을 보내면 문의 분류, 답변 받을 이메일, 제목과 내용을 문의 답변 목적으로 처리합니다. 현재 시연 모드에서는 입력 내용을 확인만 하고 저장하지 않으며, 서버를 연결한 뒤에는 관리자만 볼 수 있는 문의함에 저장합니다. 메일 서비스를 연결하면 접수 내용을 운영자 메일로도 전달합니다. 보관 기간은 운영 전에 확정합니다.

게임 소개 페이지에서 출시 알림을 신청하면 이메일 주소와 신청한 게임을 출시 소식 안내 목적으로 처리합니다. 신청은 선택 사항이며, 받은 메일의 수신 거부 주소로 언제든지 그만 받을 수 있습니다. 현재 시연 모드에서는 입력 내용을 확인만 하고 저장하지 않으며, 서버를 연결한 뒤에는 신청 내역을 저장하고 관리자 화면에는 게임별 신청 수만 표시합니다. 메일 발송을 시작할 때는 확인 메일로 본인 신청인지 먼저 확인합니다. 보관 기간은 운영 전에 확정합니다.

2. 브라우저 로컬 저장소

분석 동의 선택, 관심 프로젝트, 최근 본 프로젝트, 화면 모드, 화면 언어는 이용 중인 브라우저 로컬 저장소에, 시연 회원 닉네임과 프로젝트 η 초대장 확인 기록은 현재 탭에만 기록됩니다. 이 정보는 서버로 전송하지 않으며 아래 관리 영역 또는 브라우저 설정에서 지울 수 있습니다.

내 브라우저 데이터 관리

이 사이트가 현재 브라우저에 저장한 항목입니다. 항목별로 삭제하거나 화면 모드·화면 언어를 제외하고 한 번에 삭제할 수 있습니다.

브라우저 설정이나 개인정보 보호 모드 때문에 일부 저장소를 확인할 수 없습니다. 해당 항목은 브라우저 설정에서 직접 삭제해 주세요.

  • 저장 항목을 확인하려면 JavaScript가 필요합니다.

3. 선택형 분석 저장

개인정보 설정 화면에서 분석 저장에 동의한 경우에만 Google Analytics 4(Google LLC, 미국)로 방문한 페이지 주소, 누른 메뉴의 종류, 기기와 브라우저 정보, 대략적인 접속 지역, 브라우저에 저장되는 분석용 식별값(쿠키)을 보냅니다. 이메일, 닉네임, 댓글 내용은 보내지 않으며 광고 목적 이용은 꺼 두었습니다. 동의하지 않으면 아무것도 보내지 않고, 개인정보 설정에서 언제든 동의를 철회할 수 있습니다.

4. 상담과 외부 서비스

유효한 상담 서비스 설정 키가 없는 경우 외부 상담 스크립트를 불러오지 않습니다. 향후 외부 서비스가 연결되면 제공 업체, 처리 항목, 보유 기간을 실제 설정에 맞춰 이 문서에 추가해야 합니다.

5. 운영 전 확인 사항

운영자 정보, 연락처, 서버 저장 항목, 위탁 업체가 확정된 뒤 실제 처리 흐름과 일치하도록 최종 검토해야 합니다. 이 문서는 법률 전문가의 최종 검토를 거치지 않은 초안입니다.
