// STUDIO

DEVFORGE 소개

DEVFORGE는 서로 다른 장르의 규칙과 세계를 공개 프로젝트로 실험하는 인디 게임 개발 공간입니다.

01

장르 실험

전략, 퍼즐, RPG와 액션을 포함한 여러 형식의 플레이 규칙을 프로젝트별로 검토합니다.

02

확인된 정보 우선

확정되지 않은 출시일과 외부 판매 주소는 공개하지 않고 현재 확인 가능한 개발 상태만 안내합니다.

03

로컬 시연 단계

회원, 댓글, 굿즈와 커뮤니티 기능은 실제 서버 연결 전 화면과 흐름을 검증하는 시연 상태입니다.

프로젝트 개발 현황

// FAQ

자주 묻는 질문

프로젝트 출시 일정이 정해졌나요?

출시 일정은 확정되지 않았습니다. 확인된 개발 상태와 공개 가능한 소식만 개발 뉴스에서 안내합니다.

굿즈를 지금 구매할 수 있나요?

현재 이미지는 화면 검증용 목업입니다. 실제 판매가 시작되기 전까지 결제 기능을 제공하지 않습니다.

회원 정보와 댓글은 서버에 저장되나요?

현재 회원과 댓글 기능은 시연 모드이며 입력 내용은 서버에 저장되지 않습니다.

공식 SNS와 문의 채널은 어디인가요?

공식 외부 채널은 아직 연결되지 않았습니다. 주소가 확정되기 전에는 이동 링크를 제공하지 않습니다.

제1조 목적

본 약관은 [운영자명 또는 회사명](이하 "운영자")이 운영하는 [게임명] 공식 사이트(이하 "사이트")의 이용과 관련하여 운영자와 이용자 사이의 권리, 의무 및 책임사항을 정하는 것을 목적으로 합니다.

제2조 정의

  1. "사이트"란 운영자가 [게임명]의 소개, 홍보, 공지, 문의 접수, 이벤트 안내 등을 제공하기 위해 운영하는 웹사이트를 말합니다.
  2. "이용자"란 본 사이트에 접속하여 사이트가 제공하는 정보를 열람하거나 서비스를 이용하는 자를 말합니다.
  3. "콘텐츠"란 사이트에 게시된 문구, 이미지, 영상, 로고, 캐릭터, 세계관, 음악, 그래픽, UI, 게임 정보, 기타 자료를 말합니다.
  4. "문의"란 이용자가 사이트 내 문의 양식 또는 이메일을 통해 운영자에게 전달하는 의견, 질문, 요청 등을 말합니다.

제3조 약관의 효력 및 변경

  1. 본 약관은 사이트에 게시함으로써 효력이 발생합니다.
  2. 운영자는 관련 법령을 위반하지 않는 범위에서 본 약관을 변경할 수 있습니다.
  3. 약관이 변경되는 경우 운영자는 변경 내용, 적용일자 및 변경 사유를 사이트에 공지합니다.
  4. 이용자가 변경된 약관의 적용일 이후에도 사이트를 계속 이용하는 경우 변경된 약관에 동의한 것으로 봅니다.
  5. 이용자에게 불리하거나 중요한 내용이 변경되는 경우 운영자는 적용일 전 합리적인 기간 동안 이를 공지합니다.

제4조 서비스의 제공

운영자는 사이트를 통해 다음 서비스를 제공할 수 있습니다.

  1. [게임명] 소개 및 홍보 자료 제공
  2. 게임 관련 공지사항 제공
  3. 개발 소식, 업데이트 예정 사항, 출시 일정 안내
  4. 문의 접수 및 답변
  5. 이벤트, 사전등록, 뉴스레터 신청 기능
  6. 기타 운영자가 정하는 서비스

제5조 서비스의 변경 및 중단

  1. 운영자는 사이트 운영상 또는 기술상 필요한 경우 서비스의 전부 또는 일부를 변경하거나 중단할 수 있습니다.
  2. 운영자는 서비스 변경 또는 중단이 예정된 경우 가능한 범위에서 사전에 사이트를 통해 공지합니다.
  3. 서버 장애, 보안 문제, 천재지변, 외부 서비스 장애 등 부득이한 사유가 있는 경우 사전 공지 없이 서비스가 일시 중단될 수 있습니다.

제6조 이용자의 의무

이용자는 사이트 이용 과정에서 다음 행위를 해서는 안 됩니다.

  1. 타인의 개인정보를 무단으로 사용하는 행위
  2. 허위 정보를 입력하는 행위
  3. 사이트의 정상적인 운영을 방해하는 행위
  4. 해킹, 악성코드 유포, 비정상적 접속 시도 등 보안상 위험을 발생시키는 행위
  5. 운영자 또는 제3자의 저작권, 상표권, 초상권, 기타 권리를 침해하는 행위
  6. 욕설, 비방, 혐오, 음란, 폭력적 표현 등 부적절한 내용을 전송하는 행위
  7. 영리 목적의 광고, 도배, 스팸성 문의를 반복하는 행위
