PROJECT H

전술, 리듬 액션, 친밀도 성장이 하나로 이어지는 판타지 RPG

신의 부름을 받은 주인공은 아르데라 대륙을 여행하며 4인 파티를 편성하고, 자동 전투 위에 스킬 타이밍과 궁극기 입력을 더해 마왕 네메시스의 위협에 맞선다.

게임 구조 보기 히로인 보기
자동 전투 RPG 리듬 입력 4인 파티 100일 목표
PARTY 4인 편성

역할과 활력을 고려해 오늘의 파티를 구성한다.

RHYTHM 타이밍 조작

스킬과 궁극기는 플레이어의 박자 입력으로 강화된다.

BOND 관계 성장

선물, 대화, 이벤트가 전투 성장과 연결된다.

01

자동 전투 + 직접 개입

기본 전투는 자동으로 흐르지만, 중요한 순간의 스킬 타이밍과 궁극기 발동은 플레이어가 결정한다.

02

날짜와 시간 관리

아침, 낮, 저녁, 밤의 행동 선택이 탐험, 상점, 이벤트, 성장 계획에 영향을 준다.

03

장비와 룬 성장

전투 보상으로 장비 강화, 장비 초월, 룬 세팅, 룬 합성을 이어가며 파티를 강화한다.

04

친밀도 기반 해금

캐릭터와의 관계가 깊어질수록 대화, 전용 이벤트, 전투 보너스, 의상 콘텐츠가 열린다.

CORE LOOP

하루 단위로 반복되는 탐험과 성장

Project H의 핵심은 로비에서 준비하고, 탐험으로 전투를 진행한 뒤, 보상으로 다음 날의 선택지를 넓히는 구조다.

로비
→
파티 편성
→
탐험 선택
→
전투 진행
→
보상 획득
→
성장 투자

전투 루프

스킬 생성 → 스킬 사용 → 궁극기 게이지 충전 → 궁극기 발동으로 이어진다.

로비 성장

골드와 재화를 사용해 장비 강화, 룬 세팅, 친밀도 이벤트, 스탯 강화를 선택한다.

날짜 루프

하루는 시간 슬롯과 활력 관리로 진행되며, 100일 안에 마왕 토벌을 목표로 한다.
