Project D 다중 페이지 사이트 구성 버전

실행 방법
1. 압축을 푼다.
2. main.html을 크롬 브라우저로 연다.
3. 상단 메뉴에서 캐릭터 또는 세력 페이지로 이동한다.

포함된 페이지
- main.html: 기존 세계관 소개 메인 페이지
- characters.html: 캐릭터 소개 페이지
- factions.html: 액자식 세력 선택 페이지

핵심 기능
- main.html: 세계관 카드 슬라이더, 필터, 검색 기능
- characters.html: 소속 필터, 검색, 캐릭터 상세 패널 변경 기능
- factions.html: 이미지 액자식 세력 버튼, 클릭 시 상세 설명으로 부드러운 이동 기능

이미지 경로
- 세계관 이미지: images/world 폴더
- 세계관 카드 이미지: images/lore 폴더
- 캐릭터 이미지: images/characters 폴더
- 세력 이미지: images/factions 폴더

주의
- 실제 이미지가 없어도 그라데이션 배경으로 먼저 보이도록 구성했다.
- 나중에 이미지 파일을 넣을 때는 각 README_IMAGE_NAMES.txt에 적힌 파일명을 맞추면 된다.
