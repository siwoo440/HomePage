Core Selling Point

감성 병합 퍼즐과 치유 서사의 결합

Project B는 단순 점수 경쟁보다, 감정 합성이 망자의 자아 회복과 직접 연결되는 구조를 강조합니다.

01

경계 병동 세계관

이승과 저승 사이 병동을 중심 허브로 사용해 UI, 챕터, 스토리를 하나의 세계관으로 연결합니다.

02

7단계 감정 합성 트리

기쁨·슬픔·분노·공포에서 출발해 해탈·아가페까지. 단순 숫자 병합이 아닌 감정의 논리가 규칙입니다.

03

감정 합성 = 서사 해금

구슬을 합성하면 망자의 기억 조각이 열립니다. 퍼즐 진행 자체가 스토리 체험 과정입니다.

04

레이어드 BGM

합성 성공 시마다 멜로디 레이어가 추가됩니다. 플레이어의 행동이 음악을 완성해가는 구조입니다.

Merge System

감정이 쌓이고 합성되어 자아를 회복한다

챕터 최종 목표 감정을 완성하면 망자는 자신의 이름과 생전 감정을 기억하고 저승으로 이동합니다.

감정 단계 구조

  • 1단계기쁨·슬픔·분노·공포 (뿌리)
  • 2단계그리움·열정·설렘·절망
  • 3~5단계중간 복합·심층 복합 감정
  • 6단계사우다지·용기·숭고함 등
  • 7단계해탈·아가페·모노노아와레

합성 점수 = 단계 × 단계 × 10점 · 연쇄 합성 보너스 = 연쇄 수 × 50점
