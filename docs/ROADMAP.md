# DEVFORGE 개발 로드맵

2026년 10월 3일에 정리한 단계별 개발 방향입니다. 공통 구조를 먼저 만들고 기능을 차례로 덧붙입니다. 각 단계는 **개발 계획 → 개발 → 다음 단계 계획** 순서로 진행하고, 단계가 끝나면 이 문서의 상태를 고칩니다.

- 외부 계정·비용이 필요한 일은 7단계 이후로 모았습니다. 요금과 제약은 `docs/EXTERNAL-SERVICES.md`를 봅니다.
- 내용 결정이 필요한 일은 6단계로 모았습니다. 결정이 나기 전에는 화면에 확정되지 않은 내용을 넣지 않습니다.

## 0단계. 기반 정리와 공통 구조 (완료)

뒤 단계들이 같은 도구를 쓰도록 흩어진 것을 모으고 남은 정리를 끝냅니다.

- 페이지 적용 도구 통합: 공통 헤더·검색 설명·번역 준비 스크립트를 `pnpm pages:apply` 한 번으로 적용하고, 빠진 곳은 `pnpm pages:check`와 자동 검사가 알려 줍니다. 사이트맵 목록 누락도 검사합니다.
- 서버 공통 도구: 요청 횟수 제한(`lib/http/rate-limit.ts`)과 JSON 요청·응답 도구(`lib/http/json.ts`). 문의 양식(1단계), 댓글 제한(4단계), 출시 알림(5단계)이 함께 씁니다.
- 정적 페이지 공통 양식 전송 도구(`public/form-submit.mjs`): 전송 중 표시, 입력 오류 안내, 요청 제한·연결 실패 안내를 한곳에서 처리합니다.
- 정리: 쓰이지 않던 `public/project-detail.css` 삭제, 파일 지도의 빠진 테스트 설명 보충, 약관·개인정보 화면에 "영어 화면은 참고용 번역, 한국어 원문 우선" 안내 추가.

## 1단계. 문의 양식

문의하기 페이지에 양식을 추가합니다. 화면과 검증을 먼저 만들고 실제 발송은 7단계에서 연결합니다.

- 화면: 분류(게임·계정·굿즈·개인정보·기타), 이메일, 제목, 내용, 개인정보 수집 동의. 0단계의 양식 전송 도구 사용
- 서버: `POST /api/contact` — 입력 검증, 요청 횟수 제한, 자동 입력 방지(숨김 칸)
- 저장: 설정이 없으면 "시연 모드(저장하지 않음)"로 응답, Supabase 설정이 있으면 `contact_messages` 테이블에 저장(마이그레이션 준비)
- 관리자: 문의함 목록과 처리 상태(대기·답변 완료), 데모 화면 포함
- 영어 사전과 개인정보처리방침의 수집 항목 안내 추가

## 2단계. 로드맵 페이지

이미 있는 게임 데이터(대표·개발 중·기획 단계)로 개발 현황을 한눈에 보여 줍니다. 확정되지 않은 날짜는 넣지 않습니다.

- `public/roadmap.html`: 상태별 묶음, 장르 필터, 게임 소개 연결
- 메인의 개발 상태판에서 연결, 공통 헤더·사이트맵·영어 사전 등록(0단계 도구 사용)

## 3단계. 개발 뉴스 검색·분류

- 개발 뉴스 목록에 검색어, 종류(업데이트·신기능·데브로그·버그 수정), 게임별 필터와 주소 저장(`?q=&type=&game=`)
- 메인 게임 목록의 조건 칩·초기화 방식을 그대로 따릅니다.

## 4단계. 댓글 작성 제한

- 짧은 시간 연속 작성 제한(회원별·주소별), 같은 내용 반복 차단, 금칙어 목록과 링크 수 제한
- 로컬 서비스와 Supabase 서비스가 같은 규칙을 쓰도록 `lib/comments/rules.ts`에 추가, 데이터베이스 쪽 제한은 마이그레이션으로 준비
- 관리자 댓글 관리에 "자동 차단 사유" 표시

## 5단계. 출시 알림 신청

- 게임 소개 페이지에 "출시되면 알려 주세요" 이메일 신청(수신 동의 포함)
- `POST /api/notify` — 검증·요청 제한, 시연 모드와 Supabase 저장 준비, 수신 거부 주소
- 실제 메일 발송은 7단계의 메일 서비스 연결 뒤

## 6단계. 내용 반영 (사용자 결정·자료 필요)

- 게임 소개 28개의 실제 소개 내용, 프로젝트 δ·θ 연령 등급, 프로젝트 C·L 표기
- 굿즈 할인·임의 수치·시연 뉴스 날짜 같은 오해 소지 문구 정리
- 프레스 키트, 팀·스튜디오 소개, 채용 페이지
- 관리자 메뉴의 `DEVFORGE` 표기, 약관·개인정보처리방침 본문 확정

## 7단계. 외부 서비스 연결

1. Supabase 연결(데이터베이스 파일 순서대로 실행) → 회원·댓글·탈퇴·문의·알림 실제 확인
2. 메일 발송 서비스(가입 인증·비밀번호 재설정·문의 접수·출시 알림)
3. 간편 로그인 서비스별 앱 등록(카카오·Google부터)
4. 도메인, Vercel 배포, `SITE_URL` 설정
5. YouTube API 키, GA4 측정 ID, SNS 채널 주소

## 8단계. 공개 전 필수 점검

- 성인 게임(H·U·V) 본인인증 연결 또는 비공개 유지
- 약관·개인정보처리방침·가입 동의 문구 법률 검토, 영어 번역 검수
- 굿즈 판매처·결제 연결(사업자등록·통신판매업 신고)
- 운영 점검: 오류 기록 수집, 백업, 관리자 계정 보안

## 9단계. 해외 확장

- 영어 주소 분리(`/en/`)와 검색엔진 언어 안내, 일본어 등 추가 언어
- 번역 관리 도구 검토
