# DEVFORGE 커뮤니티 소셜 허브 설계

---

## 목표

DEVFORGE의 Discord, YouTube, X, Instagram, Facebook, TikTok을 한 페이지에서 찾고 각 채널로 이동할 수 있는 `community.html`을 만든다. 실제 API 자격 증명이 없는 개발 단계에서도 완성된 화면을 제공하고, 자격 증명이 추가되면 같은 화면이 실제 콘텐츠로 전환되게 한다.

---

## 범위

---

### 이번 구현

- 공통 헤더를 사용하는 커뮤니티 전용 페이지
- 게임별 해시태그 선택 기능
- 여섯 플랫폼을 구분한 독립 영역
- 플랫폼별 최신 소식, 반응 지표, 미디어 카드, 채널 이동 버튼
- YouTube Data API를 서버에서 호출하는 전용 API 경로
- API 키가 없거나 호출이 실패할 때 사용하는 명시적인 시연 데이터
- 메인, 굿즈, 개발 뉴스 페이지의 커뮤니티 메뉴 연결
- 메인 커뮤니티 카드에서 전용 페이지의 플랫폼 영역으로 직접 이동
- 데스크톱과 모바일 반응형 구성

---

### 이번 구현에서 제외

- SNS 계정 생성과 개발자 심사 대행
- 외부 SNS에 게시물을 자동 등록하는 기능
- Discord, X, Meta, TikTok의 실제 토큰 연결
- 외부 게시물에 대한 관리자 승인 데이터베이스
- 사용자 계정과 댓글 기능

---

## 사용자 흐름

1. 사용자가 상단 메뉴 또는 메인 커뮤니티 영역에서 커뮤니티 페이지로 이동한다.
2. 페이지 상단에서 게임을 선택한다.
3. 선택한 게임의 해시태그와 관련된 콘텐츠가 가능한 플랫폼 영역에 표시된다.
4. 사용자는 최신 콘텐츠를 확인하고 원본 게시물 또는 공식 채널로 이동한다.
5. API가 준비되지 않은 플랫폼은 `연동 준비 중` 상태와 시연 콘텐츠를 표시한다.

---

## 화면 구조

---

### 공통 헤더

메인, 굿즈, 개발 뉴스와 동일한 DEVFORGE 헤더를 사용한다. 커뮤니티 메뉴에는 `aria-current="page"`를 적용한다.

---

### 상단 소개와 게임 선택

과도하게 큰 홍보 영역 대신 페이지 목적과 게임 선택 기능을 첫 화면에 배치한다. 게임 선택은 `전체`와 프로젝트별 항목을 제공하며, 선택 결과는 URL 쿼리 `?game=project-a`와 동기화한다.

---

### 통합 주요 콘텐츠

선택한 게임의 가장 최신 YouTube 콘텐츠 한 건을 큰 카드로 보여준다. 썸네일, 제목, 채널, 게시 시각, 콘텐츠 종류, 원본 이동 버튼을 포함한다. API 미설정 상태에서는 실제 콘텐츠로 오해하지 않도록 `시연 화면` 배지를 표시한다.

---

### 플랫폼 영역

각 플랫폼은 하나의 가로 영역을 사용하며 다른 영역과 충분한 간격을 둔다. 플랫폼 제목, 연동 상태, 최신 소식, 반응 지표, 콘텐츠 카드, 채널 이동 버튼을 한 영역 안에 배치한다.

- Discord: 공지, 이벤트, 온라인 인원 자리, 서버 입장 버튼
- YouTube: 대표 영상, 최근 업로드, 라이브, 쇼츠 후보, 영상 보기 버튼
- X: 최근 게시물, 이미지·영상 여부, 좋아요·재게시·댓글 자리, 게시물 보기 버튼
- Instagram: 최근 릴스·이미지, 좋아요·댓글 자리, 게시물 보기 버튼
- Facebook: DEVFORGE 공식 페이지 공지, 반응·댓글 자리, 페이지 이동 버튼
- TikTok: DEVFORGE 공식 계정 영상, 조회·좋아요·댓글·공유 자리, 영상 보기 버튼

---

## 색상 설계

전체 배경과 타이포그래피는 기존 DEVFORGE의 어두운 네온 디자인을 유지한다. 플랫폼 고유색은 강한 단색 배경이 아니라 낮은 투명도의 배경, 테두리, 버튼 강조에만 사용한다.

- Discord: `rgba(88, 101, 242, 0.09)`
- YouTube: `rgba(255, 0, 0, 0.07)`
- X: `rgba(255, 255, 255, 0.04)`
- Instagram: `rgba(225, 48, 108, 0.07)`
- Facebook: `rgba(24, 119, 242, 0.08)`
- TikTok: `rgba(105, 201, 208, 0.07)`과 분홍색 보조 테두리

각 영역은 배경색만으로 구분하지 않고 플랫폼 이름, 아이콘, 테두리 색상도 함께 사용한다.

---

## 데이터 구조

모든 플랫폼 콘텐츠는 화면에서 같은 카드 구조로 처리한다.

- `id`: 콘텐츠 식별자
- `platform`: 플랫폼 이름
- `gameId`: 게임 식별자
- `title`: 제목 또는 본문 요약
- `author`: 작성자 또는 채널
- `publishedAt`: 게시 시각
- `url`: 원본 주소
- `thumbnailUrl`: 썸네일 주소
- `contentType`: 영상, 쇼츠 후보, 라이브, 이미지, 게시물, 공지
- `metrics`: 조회, 좋아요, 댓글, 공유 수
- `isDemo`: 시연 데이터 여부

게임 검색어는 허용 목록으로 관리한다. 브라우저에서 전달한 임의 검색어를 YouTube API에 그대로 보내지 않는다.

---

## YouTube 연동

`GET /api/community/youtube?game={gameId}` 경로를 추가한다. 서버가 `YOUTUBE_API_KEY`를 사용해 YouTube에 요청하고 정리된 JSON만 브라우저에 전달한다.

1. 허용된 게임 식별자를 해시태그와 검색어로 변환한다.
2. `search.list`로 최신순 영상 식별자와 기본 정보를 조회한다.
3. `videos.list`로 길이, 조회수, 좋아요, 댓글 수, 라이브 상태를 보완한다.
4. 결과를 15분 동안 캐시한다.
5. API 키 누락, 요청 제한, 외부 오류는 안전한 상태 코드와 빈 목록으로 반환한다.
6. 브라우저는 빈 목록을 받으면 시연 데이터를 유지하고 `YouTube 연동 준비 중`을 표시한다.

YouTube API에는 명확한 Shorts 판정 필드가 없으므로 짧은 길이의 세로형 여부를 확정하지 않는다. 짧은 영상은 `쇼츠 후보`로만 표시한다.

---

## 다른 플랫폼 연동 계약

이번 단계에서는 여섯 플랫폼이 같은 화면 계약을 사용하도록 어댑터 경계를 만든다. 실제 토큰이 준비되기 전에는 시연 데이터만 사용한다.

- X: 최근 7일 해시태그 검색 결과를 변환하는 어댑터
- Instagram: 전문 계정 권한으로 해시태그 미디어를 변환하는 어댑터
- Facebook: 관리 중인 공식 페이지 게시물을 변환하는 어댑터
- TikTok: 승인한 공식 계정의 최근 영상을 변환하는 어댑터
- Discord: 공식 서버 위젯과 공지 채널 정보를 변환하는 어댑터

비공식 화면 수집과 HTML 스크래핑은 사용하지 않는다.

---

## 링크 설정

실제 채널 주소는 한 설정 객체에서 관리한다. 주소가 없는 플랫폼 버튼은 외부로 이동하지 않고 `채널 주소 준비 중` 상태를 표시한다. `href="#"`는 사용하지 않는다.

---

## 오류와 안전 처리

- API 자격 증명은 서버 환경 변수에만 보관한다.
- 외부 콘텐츠 제목과 작성자는 일반 텍스트로 렌더링한다.
- 허용된 게임과 플랫폼만 API 요청에 사용한다.
- 외부 링크에는 새 창 보호 속성을 적용한다.
- API 결과가 없거나 실패해도 페이지 전체는 정상 표시한다.
- 외부 게시물은 민감 콘텐츠와 관계없는 결과가 섞일 수 있으므로 자동 노출 결과에 상태 안내를 표시한다.
- 실제 운영 단계에서는 관리자 숨김 목록과 신고 기능을 별도 데이터베이스 기능으로 추가한다.

---

## 반응형과 접근성

- 데스크톱은 대표 콘텐츠와 보조 카드가 나란히 보이게 한다.
- 태블릿은 두 열, 모바일은 한 열로 전환한다.
- 게임 선택과 플랫폼 이동은 키보드로 사용할 수 있게 한다.
- 상태 변경은 `aria-live`로 안내한다.
- 이미지에는 콘텐츠 제목 기반 대체 텍스트를 제공한다.
- 플랫폼 고유색만으로 상태를 전달하지 않는다.

## 파일 구성

- `public/community.html`: 커뮤니티 페이지 구조
- `public/community.css`: 여섯 플랫폼 영역과 반응형 스타일
- `public/community.mjs`: 게임 선택, 화면 렌더링, API 상태 처리
- `public/community-data.mjs`: 게임 해시태그, 채널 주소, 시연 콘텐츠
- `app/api/community/youtube/route.ts`: YouTube 서버 연동
- `lib/community/youtube.ts`: YouTube 응답 변환과 콘텐츠 분류
- `lib/community/types.ts`: 공통 콘텐츠 형식
- `tests/community-page.test.mjs`: 페이지 연결과 기본 구조 검사
- `tests/community-youtube.test.mjs`: 허용 검색어, 변환, 오류 처리 검사

## 검증 기준

- 모든 공통 헤더의 커뮤니티 메뉴가 `community.html`로 이동한다.
- 메인 커뮤니티 카드 여섯 개가 해당 플랫폼 영역으로 이동한다.
- 여섯 영역이 서로 다른 연한 고유색 배경을 사용한다.
- 게임 선택 시 URL과 표시 해시태그가 함께 변경된다.
- API 키가 없어도 시연 화면이 깨지지 않는다.
- 허용되지 않은 게임 식별자는 YouTube 요청에 사용되지 않는다.
- 외부 API 오류가 다른 플랫폼 영역을 숨기지 않는다.
- 모바일에서 가로 스크롤 없이 한 열로 표시된다.
- 기존 전체 자동 테스트와 배포 빌드가 통과한다.

## 구현 순서

1. 커뮤니티 페이지의 정적 구조와 여섯 플랫폼 색상 영역
2. 메인과 공통 헤더 연결
3. 게임 해시태그 선택과 시연 데이터 렌더링
4. YouTube 서버 API와 15분 캐시
5. 오류·빈 상태·접근성 처리
6. 자동 테스트, 모바일·데스크톱 화면 검사, 배포 빌드
