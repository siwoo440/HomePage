# DEVFORGE L5 반응형 레이아웃 안정화 설계

---
## 목적

공통 홈페이지와 Next.js 공용 화면을 320px부터 1440px까지 안정화하고, 긴 한국어 문구·200% 확대에 해당하는 유효 폭·짧은 세로 화면·가로 방향에서도 카드, 대화상자와 하단 고정 요소가 겹치거나 잘리지 않게 한다.

35개 개별 프로젝트 페이지의 전용 디자인은 변경하지 않는다. 게임·상품 데이터와 외부 API가 나중에 연결돼도 현재 레이아웃 안전 규칙을 그대로 사용할 수 있게 한다.

---
## 확인된 문제

- 320px 화면에서 개인정보 선택 패널이 `100vw`와 세로 스크롤바 폭을 함께 계산해 왼쪽이 약 3px 잘린다.
- 모바일 대화상자도 `100vw` 기반 폭을 사용해 스크롤바가 있는 브라우저에서 같은 종류의 잘림이 생길 수 있다.
- 카드와 제목 행의 일부 자식은 `min-width: 0`과 긴 문자열 줄바꿈 계약이 없어 향후 긴 게임명·상품명·뉴스 제목에서 격자 폭을 밀어낼 수 있다.
- 짧은 가로 화면에서 고정 패널과 대화상자가 콘텐츠 높이보다 작아질 때 내부 스크롤과 안전 영역 여백이 일관되지 않다.
- Next.js 로그인·성인 확인·뉴스 상세·관리자 화면은 `100vh`와 넓은 가로 묶음이 남아 있어 모바일 브라우저 UI, 확대 화면과 긴 오류 문구에 대한 공통 안전 규칙이 부족하다.

---
## 선택한 방식

공통 안전 규칙을 기존 `responsive-shell.css`에 추가하고, 실제 소유권이 있는 페이지별 CSS에는 필요한 최소 보정만 둔다.

- 공통 정적 페이지: 비프로젝트 화면의 격자·플렉스 자식 최소 폭, 긴 문구 줄바꿈, 반응형 미디어 크기를 공통 처리
- 고정 요소: `100vw` 대신 포함 영역의 `100%` 또는 양쪽 inset으로 폭을 계산하고 `100dvh` 기준 최대 높이와 내부 스크롤 제공
- 메인: 제목과 오른쪽 상세 버튼의 같은 높이 배치를 유지하면서 제목만 안전하게 줄바꿈
- 하위 페이지: 상품·뉴스·커뮤니티 카드의 텍스트, 가격, 필터와 링크가 카드 폭 안에서 줄바꿈
- Next.js: `100dvh`, 최소 폭 0, 긴 문구 줄바꿈과 좁은 화면의 작업 버튼 세로 배치 적용

전체 CSS 재작성은 기존 디자인과 35개 프로젝트 페이지에 회귀 위험이 커 제외한다. JavaScript로 화면 크기를 측정해 배치를 바꾸는 방식도 CSS만으로 해결 가능한 문제에 상태 복잡도를 더하므로 제외한다.

---
## 반응형 계약

- 320px, 390px: 단일 카드 열, 가로 스크롤 없음, 개인정보 패널·대화상자 좌우 16px 이상 안전 여백
- 768px: 메뉴 서랍, 카드 2열 또는 페이지 목적에 맞는 1열, 긴 제목이 이웃 영역을 밀지 않음
- 1024px: 가로 태블릿 카드 3열, 헤더와 필터의 자연스러운 줄바꿈
- 1280px, 1440px: 기존 데스크톱 열 수와 최대 콘텐츠 폭 유지
- 200% 확대: 1280px 화면을 640px 유효 폭으로 보는 것과 같은 모바일 재배치가 작동하고 조작 요소가 잘리지 않음
- 짧은 높이·가로 방향: 844×390px에서 메뉴 서랍, 대화상자와 동의 패널 내부가 세로 스크롤 가능
- 긴 한국어 문구: 제목·본문·상태·링크가 카드 경계를 밀지 않고 `overflow-wrap`으로 줄바꿈

---
## 검증 방식

- 브라우저 실측: `documentElement.scrollWidth === documentElement.clientWidth`와 화면 밖으로 나온 가시 요소 목록 검사
- 고정 요소 실측: 320×568px 개인정보 패널과 844×390px 대화상자의 좌우·상하 경계 및 내부 스크롤 검사
- 화면 확인: 320, 390, 768, 1024, 1280, 1440px와 844×390px에서 메인·굿즈·뉴스·커뮤니티·법적 문서·로그인·성인 확인 화면 확인
- 자동 회귀: 기존 반응형·개인정보·대화상자·페이지 테스트와 전체 `pnpm check`
