# 공통 데이터 상태 시스템 설계

---
## 목적

개발 뉴스, 상품, 커뮤니티가 서로 다른 방식으로 표시하던 로딩·데모·빈 결과·오류 상태를 하나의 계약과 디자인으로 통일합니다. 사용자는 데이터가 보이지 않는 이유와 다음 행동을 즉시 이해할 수 있어야 하며, 외부 설정이 없어도 기존 데모 콘텐츠를 계속 볼 수 있어야 합니다.

---
## 적용 범위

- 메인 페이지 상품 미리보기
- 상품 전체 페이지
- 개발 뉴스 페이지
- 커뮤니티 YouTube 피드
- 공통 상태 모듈, 스타일과 SVG 자산

개별 게임 프로젝트 페이지, 관리자 폼, 실제 외부 API 설정과 서버 데이터 저장은 이번 단계에서 제외합니다.

---
## 상태 계약

| 상태 | 의미 | 화면 동작 |
| --- | --- | --- |
| `loading` | 요청 진행 중 | 로딩 아이콘, `aria-busy`, 확인 중 문구 |
| `demo` | 외부 설정 없음 | 데모 콘텐츠 유지, 연결 전 안내 |
| `empty` | 설정은 있으나 결과 없음 | 빈 결과 아이콘, 현재 데모 유지, 다시 확인 버튼 |
| `error` | 요청 실패·시간 초과·잘못된 응답 | 오류 아이콘, 데모 유지, 다시 시도 버튼 |
| `ready` | 원격 데이터 사용 가능 | 공통 상태 패널 숨김, 실제 데이터 표시 |

뉴스와 상품의 설정 완료·빈 배열은 `empty`, 미설정 응답은 `demo`, 정상 비어 있지 않은 배열은 `ready`로 분류합니다. 커뮤니티는 전체 프로젝트 선택과 API 키 미설정을 `demo`, 정상 빈 결과를 `empty`, 성공 데이터를 `ready`로 처리합니다.

---
## 공통 모듈

`public/data-state.mjs`는 다음 기능을 제공합니다.

- 상태별 기본 제목, 설명, 아이콘과 재시도 문구 생성
- API 응답의 `ready / demo / empty` 분류
- 8초 시간 제한을 가진 JSON 요청
- 안전한 DOM API만 사용하는 상태 패널 컨트롤러
- 재시도 버튼의 중복 실행 방지

요청이 시간 제한을 넘으면 `DATA_TIMEOUT`, HTTP 실패·JSON 실패·통신 실패는 `DATA_REQUEST_FAILED` 오류로 정규화합니다.

---
## SVG 자산

외부 이미지나 라이선스가 필요한 아이콘을 사용하지 않습니다. 다음 벡터를 저장소에서 직접 관리합니다.

- `loading.svg`: 회전 가능한 궤도형 로딩 표시
- `demo.svg`: 실험실 플라스크 형태의 데모 표시
- `empty.svg`: 비어 있는 자료 상자
- `error.svg`: 경고 표시가 있는 연결 단절 아이콘

아이콘은 흰색·다크 배경에서 모두 구분되는 보라·민트·주황 계열을 사용하고 장식 이미지로 처리합니다.

---
## 페이지별 데이터 흐름

1. 페이지 초기화 시 `loading` 표시
2. 공통 시간 제한 요청 실행
3. 응답 상태 분류
4. `ready`면 원격 데이터 교체 후 패널 숨김
5. `demo` 또는 `empty`면 데모 콘텐츠 유지와 이유 안내
6. 실패하면 `error`와 재시도 버튼 표시
7. 재시도 시 다시 `loading`으로 전환하고 같은 요청 반복

요청 순번을 사용해 이전 요청이 늦게 끝나도 최신 화면 상태를 덮어쓰지 못하게 합니다.

---
## 접근성과 반응형

- 상태 패널은 `role="status"`, `aria-live="polite"` 사용
- 로딩 중에만 `aria-busy="true"` 적용
- 아이콘은 빈 `alt`와 `aria-hidden="true"`로 중복 낭독 방지
- 재시도 버튼은 실제 `<button>` 사용
- 620px 이하에서는 아이콘·문구·버튼을 세로 배치
- 움직임 축소 환경에서는 로딩 아이콘 회전 중단

---
## 오류와 대체 정책

- 네트워크 오류와 시간 초과에도 기존 데모 카드 제거 금지
- 오류 메시지에 내부 코드, 키와 서버 응답 원문 노출 금지
- 재시도 실패 시 동일 오류 상태 유지
- 필수 상태 호스트가 없으면 페이지 기능을 중단하지 않고 안전하게 무시
- 실제 원격 데이터가 성공한 경우에만 데모 콘텐츠 교체
