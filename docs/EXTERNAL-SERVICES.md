## 1. Supabase (회원·댓글·뉴스·상품 저장)

- 무료: DB 500MB, 파일 저장 1GB, 월간 활성 사용자 5만 명, 전송량 5GB, 활성 프로젝트 2개
- 무료 제약: 1주일 동안 활동이 없으면 프로젝트가 일시정지됩니다. 운영 사이트는 Pro를 권장합니다.
- Pro: 월 $25부터(월간 활성 사용자 10만, 디스크 8GB, 전송량 250GB, 파일 저장 100GB, 컴퓨트 크레딧 $10 포함)
- 기본 메일: 시간당 2통, 조직 팀원 주소로만 발송되어 회원가입 인증·비밀번호 재설정에는 쓸 수 없습니다.
- 출처: https://supabase.com/pricing, https://supabase.com/docs/guides/auth/auth-smtp

## 2. 메일 발송(커스텀 SMTP)

- Resend: 무료 월 3,000통(하루 100통, 도메인 3개), Pro 월 $20(5만 통)
- Amazon SES: 1,000통당 $0.10, 신규 계정은 6개월 동안 쓸 수 있는 최대 $200 크레딧
- 공통: 보내는 주소의 도메인 인증(SPF·DKIM)이 필요하므로 도메인을 먼저 준비합니다.
- 출처: https://resend.com/pricing, https://aws.amazon.com/ses/pricing/

## 4. Vercel (사이트 배포)

- Hobby(무료): 개인·비상업 용도로 제한됩니다. 월 CDN 요청 100만, 전송량 100GB, 함수 호출 100만, 활성 CPU 4시간
- Pro: 개발자 좌석당 월 $20(매달 $20 크레딧 포함, 전송량 1TB, CDN 요청 1,000만), 조회 전용 좌석은 무료
- 판단: 스튜디오 홍보·굿즈 판매 사이트는 상업용으로 보는 것이 안전하므로 공개 운영 시 Pro를 권장합니다.
- 출처: https://vercel.com/pricing

## 5. 도메인

- 가비아: .com 첫해 19,800원, .kr·.co.kr 정가 23,100원(첫해 할인 16,500원, 부가세 포함)
- Cloudflare Registrar: 원가 판매(.com 약 $10.46, 2026년 11월 1일부터 약 $11.15 예정 — 비공식 자료), DNS 무료
- 도메인을 정하면 `.env.local`·Vercel의 `SITE_URL`과 Supabase 인증 주소를 바꿉니다(README 7단계).
- 출처: https://domain.gabia.com, https://www.cloudflare.com/products/registrar/

## 6. YouTube Data API v3 (커뮤니티 영상)

- 비용 없이 쿼터로 제한합니다. 기본은 하루 10,000 units(검색은 별도 하루 100회).
- 쿼터를 늘리려면 "Audit and Quota Extension Form"을 제출하고 정책 준수 심사를 받습니다(비용 언급 없음 **[미확인]**).
- 이 사이트는 서버에서 결과를 캐시하므로 일반 방문량으로는 기본 쿼터로 충분할 가능성이 큽니다.
- 출처: https://developers.google.com/youtube/v3/determine_quota_cost, https://developers.google.com/youtube/v3/guides/quota_and_compliance_audits

## 7. Google Analytics 4

- 무료: 데이터 보존 최대 14개월, 맞춤 측정기준·측정항목 50개, 키 이벤트 30개, BigQuery 일일 내보내기 100만 이벤트
- 개인정보보호법: 개인정보처리방침에 행태정보 수집, 쿠키 사용, 국외 이전(Google)과 거부 방법을 적어야 합니다. 이 사이트는 동의 전 분석을 실행하지 않습니다. 동의 배너의 법적 의무 여부는 해석이 갈리므로 법률 검토를 권장합니다.
- 출처: https://support.google.com/analytics/answer/11202874

## 8. 굿즈 판매

- 네이버 스마트스토어(2025년 6월 개편 기준): 판매수수료 일반 유입 3.003%, 마케팅 링크 유입 1.001%, 네이버페이 주문관리 수수료 1.98%(영세)~3.63%(일반) **[2026년 추가 개편 미확인]**
- 토스페이먼츠(자체 결제): 가입비 220,000원(최초 1회), 연관리비 110,000원(계약 형태별 상이), 카드 3.4%, 계좌이체 2.0%(최저 200원), 가상계좌 건당 400원(부가세 별도). 영세·중소 우대 수수료는 자동 적용
- 법적 요건: 계속·반복 판매는 사업자등록이 필요합니다. 통신판매업 신고는 원칙적으로 의무이며 직전 연도 거래 50회 미만 등은 면제지만, 결제대행사·오픈마켓이 신고증을 요구하는 경우가 많습니다.
- 권장: 처음에는 스마트스토어로 판매하고 홈페이지는 상품 소개와 판매처 링크만 두는 방식이 초기 비용이 가장 적습니다.
- 출처: https://www.tosspayments.com/about/fee, https://www.consumer.go.kr

## 9. 성인(19+) 본인인증 — 중요

- 청소년보호법 제16조와 시행령 제17조에 따라, 청소년유해매체물은 신용카드·휴대전화 인증 같은 정해진 수단으로 나이와 본인 여부를 확인해야 합니다. 법제처 해석상 **생년월일 자기 입력만으로는 부족**합니다.
- 현재 프로젝트 H·U·V의 성인 확인은 개발용 자기 확인 방식이므로, 실제 성인 콘텐츠를 공개하기 전에 본인인증 서비스로 바꾸거나 해당 콘텐츠를 비공개로 둡니다.
- 비용 예시(포트원 안내): 다날 휴대폰 인증 월정액 5만 원(1,200건, 건당 약 42원)부터·직계약 가입비 10만 원, KG이니시스 통합인증 건당 40원, 포트원 경유 시 가입비 무료. NICE·KCB 정가는 비공개 **[미확인]**
- 계약에 사업자등록이 필요할 가능성이 높습니다 **[미확인]**.
- 출처: https://www.moleg.go.kr (법령해석 cs_seq=105762), https://blog.portone.io/authorization-payment-2/

## 10. 상담 채팅 (채널톡)

- 무료: 고객 메신저(최근 30일 상담만 조회)와 사내 메신저
- 유료: 얼리스테이지 월 2.7만 원부터, 그로스 월 9만 원부터(25% 할인 표시가, 부가세 별도)
- 출처: https://channel.io/ko/pricing

## 11. 뉴스레터

- 스티비: 무료 구독자 500명·월 2회 발송, 스탠다드 월 8,900원부터(500명 구간, 발송 무제한) **[부분 확인]**
- Mailchimp: 무료 연락처 250명·월 500통, Essentials 월 $13부터, Standard 월 $20부터
- 공통: 광고성 정보는 수신 동의를 받고, 모든 메일에 수신 거부 방법을 넣어야 합니다.
- 출처: https://help.stibee.com, https://mailchimp.com/pricing/marketing/

## 12. 영어 번역 검수

- 프리랜서: 한글 글자당 30~40원, 업체: 영어 단어당 150원 이상, 원어민 감수만: 단어당 약 60원(대학 통번역센터 기준)
- 현재 사전(`public/i18n/en/`)을 그대로 검수용 자료로 넘길 수 있습니다. 약관·개인정보처리방침은 우선 검수 대상입니다.

## 13. ChatBot용 LLM API

- 입력·출력 토큰 수에 따라 내는 종량제이며 출력 단가가 더 비쌉니다. 큰 모델일수록 단가가 높고, 프롬프트 캐싱·배치 처리로 할인됩니다.
- API 키는 서버에만 두고, 월 사용량 상한과 예산 알림을 설정합니다.
- 출처: https://claude.com/pricing

## 연결 순서 제안

1. **무료로 시작:** Supabase 무료, Resend 무료, Google·카카오·Discord 로그인, YouTube API, GA4
2. **공개 직전:** 도메인 구매, Vercel Pro, Supabase Pro(일시정지 방지), 약관·개인정보 법률 검토
3. **판매·성인 콘텐츠 전:** 사업자등록·통신판매업 신고, 스마트스토어 또는 결제대행 계약, 성인 본인인증 계약
4. **필요할 때:** Apple 로그인, 채널톡, 뉴스레터, 번역 검수
