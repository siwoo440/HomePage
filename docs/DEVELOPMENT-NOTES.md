# DEVFORGE 개발 노트

이 문서는 2026년 9월 26일 기준으로 DEVFORGE 홈페이지의 후속 개발 항목을 실행 조건에 따라 분류한 기록입니다. 현재는 외부 서비스 계정, 비밀 키, 판매처, 공식 도메인과 예산이 확정되지 않았으므로 로컬에서 검증할 수 있는 작업을 먼저 진행합니다.

ChatBot 본체와 Text-Play는 별도 저장소에서 관리합니다. 이 저장소에서는 DEVFORGE 홈페이지와 ChatBot 홍보 링크만 다룹니다.

---
## 1. 분류 기준

| 구분 | 판단 기준 | 현재 처리 원칙 |
| --- | --- | --- |
| 로컬 구현 가능 | 외부 계정, 비밀 키, 결제와 별도 계약 없이 코드·데모 데이터·브라우저 저장소로 완성하고 검사할 수 있음 | 먼저 구현하고 자동 테스트와 로컬 화면으로 검증 |
| 외부 API·계정 필요 | 서비스 가입, 프로젝트 생성, API 키, OAuth 설정 또는 실제 배포 주소가 있어야 통합 검증 가능 | 인터페이스와 대체 화면만 로컬에서 준비하고 실제 연결은 보류 |
| 비용·구매 필요 | 도메인 구입, 유료 사용량, 거래 수수료, 전문가 검토 또는 상용 라이선스가 필요함 | 예산과 공급자가 확정된 뒤 진행 |

무료 요금제가 있더라도 가입, 키 발급 또는 외부 통신이 필요하면 `외부 API·계정 필요`로 분류합니다. 무료 한도를 넘을 때만 비용이 발생하는 서비스는 외부 항목에 기록하고 유료 전환 조건을 별도로 표시합니다.

---
## 2. 현재 개발 제약

- Supabase 프로젝트 주소, 공개 키와 실제 관리자 계정 없음
- YouTube Data API 키 없음
- GA4 측정 ID 없음
- 공식 배포 주소와 도메인 없음
- ChatBot의 확정 배포 주소 없음
- 상품 판매처, 결제대행사와 재고 API 미정
- 상담 서비스 공급자와 플러그인 키 미정
- 전문 성인 본인인증 서비스 미정
- 이용약관과 개인정보처리방침의 법률 검토 미완료
- 실제 상품 사진, 가격, 판매 조건과 재고 정책 미확정
- 외부 서비스 비용과 월간 사용량 예측 자료 없음

확인되지 않은 계정·비밀 키·가격·법적 효력을 추측하지 않습니다. 외부 연결이 필요한 기능은 데모 모드와 안전한 실패 화면을 유지합니다.

| 우선순위 | 의미 | 적용 기준 |

| P1 | 공개 품질을 위해 구현 | 사용성, 화면 일관성, 상태 안내와 관리 편의 |

| 보류 | 현재 조건으로 완료 판정 불가 | 계정, 키, 계약, 예산 또는 법률 검토 필요 |

## 5. 외부 API·계정이 있어야 완료 가능한 개발 요소
